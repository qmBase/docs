title: Wie kann ich den Schnellzugriff auf der Startseite konfigurieren
keywords:
  - Allgemein
  - Startseite
---

Der Schnellzugriff auf der Startseite kann im Administratorbereich unter _/Konfiguration/Startseite_ für alle Nutzer des Systems global konfiguriert werden.
