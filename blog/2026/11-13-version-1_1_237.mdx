📢 Self-Hosting unter Windows? Bitte beachten Sie die Informationen in diesem Blog-Beitrag zur Installation und Aktualisierung von qmBase auf Windows-Systemen.

Zu den Neuerungen gehören zusätzlich: Word-Dokumente lassen sich jetzt direkt im Browser anzeigen, und überarbeitete Auswahlfelder sorgen für ein einheitlicheres, besser lesbares Design – auch im Dark Mode.

{/* truncate */}

## Allgemein

- **Auswahlfelder:** Die meisten Auswahlfelder verfügen jetzt über ein moderneres Design. Sie haben ein einheitliches Erscheinungsbild in der gesamten Anwendung und sind dadurch besser lesbar – auch im Dark Mode.
- **Vorschau von Word-Anhängen (.docx & .doc):** Ab sofort können angehängte Word-Dokumente direkt im Browser angezeigt werden, ohne dass sie zuvor heruntergeladen werden müssen.
  Durch Klicken auf eine Word-Datei in der Liste der verbundenen Dateien oder über die Option Vorschau im Dropdown-Menü Aktionen wird das Dokument in einem schreibgeschützten Vorschaufenster geöffnet.
  Über die Schaltfläche Herunterladen in der Fußzeile des Fensters kann die Datei bei Bedarf weiterhin direkt heruntergeladen werden.

### Framework Update - On Premise Windows-Installationen bitte beachten

Bitte beachten Sie, dass für On-Premise Installationen und Updates das ASP.NET Core Hosting Bundle 11.x erforderlich ist. Stellen Sie sicher, dass Ihre Umgebung entsprechend aktualisiert wurde, bevor Sie das Update einspielen.
Weitere Informationen zum Self-Hosting auf Windows finden Sie in unserer [Installationsanleitung](/docs/technical/self-hosting/install-windows).

Nutzer der Docker Self-Hosting Variante müssen keine manuellen Anpassungen am Hosting Bundle vornehmen.

Sollten Sie Interesse an der Docker Self-Hosting Variante haben, finden Sie weitere Informationen in unserer [Docker Self-Hosting Anleitung](/docs/technical/self-hosting/docker).
Kontaktieren Sie unseren [Support](mailto:support@qmbase.com), falls Sie Fragen zur Aktualisierung Ihrer On-Premise Windows-Installation haben oder zum Beispiel auf die Docker-Installation wechseln möchten.
